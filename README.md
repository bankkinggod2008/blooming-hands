# Blooming Hands Music Studio V4 — Finger Melody & 10-Chord Studio

เว็บเล่นโน้ตและคอร์ดด้วยท่ามือผ่านกล้อง รองรับ 2 มือ (รวม 0–10 นิ้ว) เปิดได้ทั้งคอมและมือถือ

## สิ่งที่แก้ไขจาก V3

- **แก้ปัญหาเงียบเมื่อเลือกเพลง Txrbo หรือ LANDOKMAI ที่ยังไม่ได้อัปโหลด MP3:** เพิ่มเครื่องดนตรีสังเคราะห์ Web Audio เล่นโน้ตได้โดยไม่ต้องมีไฟล์เพลงหรือกล้อง
- มีปุ่ม **🔊 ทดสอบเสียง** (ได้ยินคอร์ดสั้น ๆ) และปุ่มจำลองนิ้ว **1–10** ทดสอบก่อนเปิดกล้องได้
- **โหมดเล่นเมโลดี:** เมื่อกล้องตรวจพบจำนวนชูนิ้วที่เปลี่ยนอย่างเสถียร จะเล่นโน้ตตัวถัดไปในทำนองฝึกที่แต่งใหม่ตามเพลงที่เลือก ไม่ใช่การถอดโน้ตเพลงต้นฉบับ หากต้องการเล่นโน้ตต่อด้วยจำนวนเดิม ให้ลดมือเป็น 0 ก่อนแล้วยกขึ้นใหม่
- **โหมดคอร์ด 10 นิ้ว:** นิ้ว 1–10 (นับสองมือรวม) ตรงกับคอร์ด 10 แบบที่ต่างกัน; 10 นิ้ว = คอร์ดที่ 10
- นับและแสดงจำนวนชูนิ้วบนจอ ลดการกระตุกด้วยการคัดกรองท่าค้าง 165 มิลลิวินาที
- เสียงเครื่องดนตรีไม่ถูกลดเหลือศูนย์เมื่อมือหยุดเคลื่อนไหว การปรับความดังตามมือเดิมใช้กับแบ็กกิ้ง MP3 เท่านั้น
- ปรับเลย์เอาต์มือถือให้ไม่มีแสงตกแต่งล้นจอ

## การใช้งาน

1. เปิดหน้าเว็บไซต์ผ่าน HTTPS หรือ localhost
2. **กด “🔊 ทดสอบเสียง” ก่อน** เพื่อปลดล็อกระบบเสียง (โดยเฉพาะ Safari/iPhone)
3. หากได้ยินคอร์ด สามารถกดปุ่ม 1–10 เพื่อทดลองเสียงได้ทันที **ไม่ต้องเปิดกล้อง**
4. เลือกโหมด **เล่นเมโลดี** หรือ **คอร์ด 10 นิ้ว**
5. กด **เปิดกล้อง เริ่มเล่น** และอนุญาตสิทธิ์กล้อง แล้วยกมือให้เห็นครบทั้งนิ้ว
6. ลองชู 1, 2, 3, ... นิ้ว หรือยกทั้งสองมือเพื่อให้ครบ 6–10 นิ้ว
7. เลือกเพลงจากรายการด้านขวา ระบบจะเปลี่ยนชุดโน้ต/คอร์ดฝึกที่แต่งใหม่ตามสไตล์เพลง

## เพลงที่รองรับ

- มีเพลงบรรเลงต้นฉบับ 6 ไฟล์ MP3 ใน `assets/tracks/`
- มีรายการเลือก **Txrbo – ต่อยให้** และ **LANDOKMAI – เพลงรักเพลงแรก** พร้อมปุ่ม YouTube สำหรับฟังต้นฉบับ
- **ZIP ไม่ได้รวมเสียงจริงหรือทำนองที่ถอดจากเพลงของศิลปินทั้งสอง** และเมโลดีฝึกในเว็บไม่ใช่เพลงต้นฉบับของศิลปิน
- ถ้ามีไฟล์เพลงที่ได้รับอนุญาตให้ใช้งาน สามารถกด “เพิ่มไฟล์” เพื่อเล่นเป็นแบ็กกิ้งประกอบโน้ตสังเคราะห์ได้

## เปิดบน Windows

ดับเบิลคลิก `START_WEBSITE.bat` (ต้องมี Python) หรือรันคำสั่ง:

```powershell
py -m http.server 8000
```

แล้วเปิด `http://localhost:8000` บนเบราว์เซอร์

## เปิดบนมือถือ

อัปโหลด **ไฟล์ทั้งหมดภายในโฟลเดอร์นี้** รวมถึง `assets/tracks/` ไปที่ GitHub Pages แล้วเปิดลิงก์ HTTPS บน Safari/Chrome มือถือ ปุ่มทดลองนิ้วและเครื่องดนตรีใช้ได้โดยไม่ต้องเปิดกล้อง แต่กล้องต้องได้รับสิทธิ์และต้องเปิดผ่าน HTTPS (หรือ localhost บนอุปกรณ์เดียวกัน)

## ถ้ายังไม่ได้ยินเสียง

1. กด **ทดสอบเสียง** และตรวจว่าขึ้น “✓ เสียงพร้อมใช้งาน”
2. เพิ่มระดับเสียงของเครื่องและแถบความดังของเว็บ ตรวจว่าไม่ได้เปิดปุ่มปิดเสียง ♩
3. iPhone: ตรวจระดับเสียงสื่อและใช้ Safari เวอร์ชันใหม่; เสียบหูฟังเพื่อตรวจว่ามีเสียงไปออกทางอุปกรณ์อื่นหรือไม่
4. หากต้องการฟังไฟล์ MP3 ให้เลือกเพลงที่มีไฟล์แล้วกด ▶ — **ปุ่มเล่นไม่ได้ดาวน์โหลดเพลงจาก YouTube**
5. เปิดแอป/เบราว์เซอร์ใหม่อีกครั้งหาก audio context ถูกระงับในโหมดประหยัดพลังงาน
6. ถ้าไม่ตรวจจับนิ้ว ให้ดูแลแสงและพื้นหลัง ไม่ให้นิ้วทับกัน ถือสองมืออยู่ในกรอบ และรอประมาณ 0.2 วินาทีต่อท่า

## ข้อจำกัด / ความเป็นส่วนตัว

- โมเดลตรวจจับมือใช้ MediaPipe ผ่าน CDN: อินเทอร์เน็ตจำเป็นสำหรับโหลดไลบรารีและโมเดลครั้งแรก
- การนับนิ้วแบบภาพไม่สมบูรณ์ 100% โดยเฉพาะนิ้วโป้ง เมื่อนิ้วบังกัน หรือแสงไม่พอ
- กล้องประมวลผลในเบราว์เซอร์ ไฟล์เสียงที่ผู้ใช้เลือกเล่นในอุปกรณ์ ไม่อัปโหลดให้เซิร์ฟเวอร์โดยโค้ดของเว็บไซต์
- เมื่อใช้งานจริงบน iOS/Android ควรทดสอบสิทธิ์กล้องและการปลดล็อก Web Audio เพิ่มเติม เพราะไม่ใช่อุปกรณ์ที่ใช้ตรวจสอบในชุดพัฒนานี้

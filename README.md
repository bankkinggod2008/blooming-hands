# Blooming Hands — Hand-Tracking Chorus Studio

เว็บอินเทอร์แอกทีฟที่ใช้กล้องตรวจจับมือด้วย **MediaPipe Hand Landmarker** และเปลี่ยนการเคลื่อนไหวเป็นระดับเสียงแบบเรียลไทม์

## เริ่มต้นใช้งาน (Windows 11)

1. แตกไฟล์ ZIP แล้วเข้าโฟลเดอร์ `hand-chorus-website`.
2. ดับเบิลคลิก `START_WEBSITE.bat` (ต้องมี Python ติดตั้งไว้) หรือเปิด Terminal ในโฟลเดอร์แล้วพิมพ์ `py -m http.server 8000` หรือ `python -m http.server 8000`.
3. เปิด Chrome/Edge แล้วไปที่ **http://localhost:8000**.
4. กด **เปิดกล้อง & เริ่มเล่น** แล้วเลือก **อนุญาต** เมื่อเบราว์เซอร์ขอสิทธิ์กล้อง.
5. แบมือและขยับมือเพื่อเล่นเสียงประสาน / ขยับเร็วขึ้นให้เสียงดังขึ้น / กำมือเพื่อค่อย ๆ ลดเสียง.
6. ต้องการได้ยินท่อนคอรัสของเพลงจริง? กด **อัปโหลดเสียงท่อนคอรัสของคุณ** และเลือกไฟล์เสียงที่คุณมีสิทธิ์ใช้จากเครื่อง จากนั้นปรับเวลา **เริ่มวินาที** / **สิ้นสุดวินาที** ให้ตรงกับท่อนที่ต้องการ.

> เสียงตัวอย่างเริ่มต้นเป็นเสียงสังเคราะห์ original chord pad ไม่ใช่ไฟล์เพลงหรือเมโลดี้จาก LANDOKMAI. โปรเจกต์ไม่ได้ดาวน์โหลด/ดึงแทร็กเสียงจาก YouTube และไม่แนบเพลงที่มีลิขสิทธิ์.

## ไฟล์
- `index.html` — โครงหน้าเว็บ
- `styles.css` — การตกแต่งและ responsive
- `app.js` — MediaPipe, webcam, Web Audio และควบคุมระดับเสียงจากมือ
- `START_WEBSITE.bat` — สตาร์ต local server แล้วเปิดหน้าเว็บ (Windows)

## เงื่อนไขการใช้งาน
- **ต้องมีอินเทอร์เน็ตในการโหลด MediaPipe package และโมเดลจาก CDN ครั้งแรก/ทุกครั้งที่ไม่อยู่ในแคช**; หน้าเว็บส่วนที่เหลือรันในเครื่อง.
- **กล้อง** ต้องเปิดใน secure context: `http://localhost` หรือโฮสต์ผ่าน `https://` (เช่น GitHub Pages). ไม่แนะนำเปิด `index.html` ผ่าน `file://` เพราะ module imports/สิทธิ์กล้องอาจทำงานไม่เหมือนกันในแต่ละเบราว์เซอร์.
- ภาพจากกล้องถูกใช้ในเบราว์เซอร์สำหรับการตรวจจับมือ ไม่มีโค้ดบันทึกหรืออัปโหลดภาพกล้อง. ไฟล์เสียงที่เลือกจะเล่นจาก object URL ภายในเบราว์เซอร์.
- โมเดล MediaPipe มีการดาวน์โหลดจาก Google CDN / jsDelivr ตามที่ระบุใน `app.js` (นโยบายข้อมูล/การวัดประสิทธิภาพขึ้นอยู่กับผู้ให้บริการไลบรารี).
- รองรับ Chrome/Edge รุ่นปัจจุบันดีที่สุด; อุปกรณ์ระดับล่างอาจได้อัตราเฟรมต่ำกว่า.

## หาก Windows ไม่มี Python
ติดตั้ง Python จาก python.org และทำเครื่องหมาย **Add Python to PATH** ระหว่างติดตั้ง แล้วลองเปิด `START_WEBSITE.bat` อีกครั้ง. อีกทางคือใช้ VS Code + Live Server เปิด `index.html`.

## ปัญหาที่พบบ่อย
- กล้องไม่เปิด: อนุญาต Camera ใน Windows Settings > Privacy & security > Camera และให้สิทธิ์กล้องแก่เบราว์เซอร์.
- ไม่มีเสียง: ตรวจระดับเสียง Windows, ลองกดปุ่ม **ทดลองฟังเสียงตัวอย่าง**, เปิดแท็บที่ไม่ได้ mute; เสียงถูกปลดล็อกหลังการกดปุ่มตามนโยบาย autoplay ของเบราว์เซอร์.
- AI ไม่โหลด: ตรวจอินเทอร์เน็ตและ CDN/Firewall; ดู Console ใน DevTools (F12).
- เล่นไฟล์ไม่ออก: ลองแปลงไฟล์เสียงเป็น MP3 หรือ WAV และเลือกไฟล์ใหม่.

# Blooming Hands — Music Studio V3

เว็บเล่นเพลงด้วยการตรวจจับมือผ่านกล้อง ใช้ได้ทั้งคอมและมือถือเมื่อเปิดผ่าน HTTPS (หรือ localhost บนคอม)

## สิ่งที่เพิ่มใน V3

แท็บ **เพลงที่ขอ** แสดง 2 รายการ:
1. Txrbo — ต่อยให้: https://www.youtube.com/watch?v=SW-aUT_3a1g
2. LANDOKMAI — เพลงรักเพลงแรก (Blooming): https://www.youtube.com/watch?v=N9bashij_7c

แต่ละเพลงมีปุ่ม **เพิ่มไฟล์** สำหรับนำไฟล์ MP3/WAV/M4A ที่คุณมีสิทธิ์ใช้จากเครื่องของคุณมาเล่นและควบคุมด้วยมือ และมีปุ่ม **YouTube** สำหรับไปฟังเพลงต้นฉบับบนเว็บไซต์ YouTube โดยตรง

**สำคัญ:** ใน ZIP **ไม่มีเสียงเพลงต้นฉบับของ Txrbo หรือ LANDOKMAI** และไม่มีการดาวน์โหลดหรือแยกเสียงจาก YouTube มาใช้โดยอัตโนมัติ การเปิด YouTube ต่างจากระบบเล่นเพลงควบคุมด้วยมือภายในเว็บ; หากต้องการควบคุมเพลงนั้นด้วยมือ ต้องเพิ่มไฟล์เสียงที่มีสิทธิ์ใช้งานเอง

### วิธีเพิ่มเพลงทั้งสอง

1. เปิดเว็บและเข้าแท็บ **เพลงที่ขอ**
2. กด **＋ เพิ่มไฟล์** ข้างเพลงที่ต้องการ
3. เลือกไฟล์เสียงจากมือถือหรือคอม (MP3, WAV, M4A หรือไฟล์เสียงอื่นที่เบราว์เซอร์รองรับ)
4. กด ▶ เพื่อฟังเพลง หรือกด **เปิดกล้อง เริ่มเล่น** เพื่อใช้การเคลื่อนไหวของมือควบคุมเสียง
5. ใช้กล่อง **เลือกช่วงเพลงที่ต้องการวน** เพื่อเลือกท่อนคอรัสเป็นวินาทีได้

เว็บจะพยายามจำไฟล์ของสองเพลงนี้บน **เบราว์เซอร์และอุปกรณ์เดียวกัน** ผ่าน IndexedDB เพื่อให้ไม่ต้องอัปโหลดทุกครั้ง หากโหมดส่วนตัว/พื้นที่จัดเก็บไม่รองรับหรือไฟล์ใหญ่เกินโควตา ระบบจะเล่นได้ในหน้านั้น แต่หลังรีเฟรชอาจต้องเพิ่มไฟล์อีกครั้ง ข้อมูลไม่ได้ซิงค์ข้ามเครื่องหรือบัญชี GitHub

## เพลงบรรเลง

ไฟล์ `assets/tracks/` มีเพลงบรรเลงสร้างขึ้นใหม่ 6 เพลงจาก V2 ไม่ใช่เพลงของศิลปิน:
- Blooming Garden
- Neon Sunset
- Moonlit Coffee
- Peach Disco
- Cloud Nine
- Morning Pixels

แท็บ **เพลงของฉัน** เพิ่มไฟล์เพลงอื่นหลายเพลงได้ แต่เพลงในแท็บนี้จะถูกลบเมื่อรีเฟรชหน้า

## วิธีเปิดบน Windows

แตก ZIP จากนั้นดับเบิลคลิก `START_WEBSITE.bat` (ต้องติดตั้ง Python) หรือเปิด terminal ในโฟลเดอร์นี้แล้วรัน `py -m http.server 8000` ก่อนเข้า `http://localhost:8000`

## วิธีเล่นบนมือถือ

1. สร้าง GitHub repository แล้วอัปโหลด `index.html`, `styles.css`, `app.js`, `START_WEBSITE.bat` และ **โฟลเดอร์ `assets/` ให้ครบ**
2. เปิด Settings → Pages → Deploy from a branch → main / (root)
3. เปิดลิงก์ GitHub Pages แบบ HTTPS ใน Safari หรือ Chrome
4. อนุญาตกล้อง ยกมือให้กล้องเห็นชัด แล้วโบกหรือกำมือเพื่อปรับระดับเสียง

ห้ามเปิดด้วย `http://IP-คอม:8000` บนมือถือแล้วคาดว่าจะใช้กล้องได้เสมอ เพราะ API กล้องบนมือถือจำเป็นต้องใช้ secure context เช่น HTTPS

## ความเป็นส่วนตัวและข้อจำกัด

- กล้องและไฟล์เพลงที่เพิ่มเข้ามาประมวลผลบนอุปกรณ์ผู้ใช้ ไม่ได้อัปโหลดให้เซิร์ฟเวอร์
- ระบบตรวจจับมือใช้ MediaPipe และต้องมีอินเทอร์เน็ตสำหรับโหลดโมเดลและไลบรารีในครั้งแรก
- สื่อเสียงที่เลือกได้ต้องเป็นไฟล์รูปแบบที่เบราว์เซอร์ของอุปกรณ์รองรับ
- การเล่นอัตโนมัติบน iPhone อาจต้องกดปุ่ม ▶ ซ้ำหลังให้สิทธิ์กล้อง
- หลีกเลี่ยงการเผยแพร่หรืออัปโหลดไฟล์เพลงที่ไม่มีสิทธิ์เผยแพร่ลงใน GitHub repository
